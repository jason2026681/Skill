# 初次归档评审检查清单

适用场景：产品/单板**首次**提交生产资料归档时，对整套归档文件做合规性检查。检查结果只记录问题项。

---

## 1. 齐套性检查（通用）

| #    | 检查项                                                                                             |
| ---- | ----------------------------------------------------------------------------------------------- |
| G-01 | 整机 BOM中备注写明“按图加工”的结构都有对应的图纸文件夹，而且文件夹里有图纸，整机BOM里的结构件物料编码、物料名称、版本、型号与结构物料文件夹里的物料编码、物料名称、版本、型号对应一致 |
| G-02 | 整机BOM和单板BOM里面备注标注“关键件”或“关键器件”或“关键物料”的物料都应在《产品关键物料清单》文件夹里找到对应的规格书，型号要求一致对应                       |

## 2. 整机 BOM 检查

| #     | 检查项                                                |
| ----- | -------------------------------------------------- |
| B1-01 | BOM 有唯一编码、版本号                                      |
| B1-02 | 修订记录里每个版本都有记录变动，无版本跳动或遗漏                           |
| B1-03 | 封面的产品名称、产品型号、物料编码、BOM版本与主页里的产品名称、产品型号、物料编码、版本一致    |
| B1-04 | 单板 BOM版本ERP、版本、板卡型号与整机BOM里对应的单板BOM物料编码、版本、物料名称对应一致 |
| B1-05 | 备注里标明“关键物料”或“关键器件”或“关键件”的物料要有物料编码                  |
| B1-06 | 审批签署栏里可以没有内容                                       |

## 3. 单板 PCB检查

| #     | 检查项                                       |
| ----- | ----------------------------------------- |
| GP-01 | 《PCB-加工工艺要求说明卡》文件里的PCB文件版本号要与单板BOM里的版本号一致 |
| GP-02 | 《PCB-加工工艺要求说明卡》里不能体现PCB设计工具名称             |

## 4. 单板 BOM 检查

| #     | 检查项                                                                                                                                                     |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B2-01 | 单板 BOM版本ERP、版本、板卡型号与整机BOM里对应的单板BOM物料编码、版本、物料名称对应一致                                                                                                      |
| B2-02 | 单板BOM里的PCB物料编码、物料名称、型号、版本与《PCB》文件夹里的对应内容一致                                                                                                              |
| B2-03 | 单板BOM的修订记录里每个版本都有修订记录描述，无版本跳动或遗漏，最后改动的版本要与当前BOM版本一致                                                                                                     |
| B2-04 | 单板BOM里电容、电阻的型号、参数描述、封装的关键内容要对应一致，不能互相矛盾，比如参数描述封装是0402，封装里面写0201，只用关注0603、0402、0201等的尺寸描述，前缀SL/SR/SC不影响结果，比如型号里写10pF，参数描述里写15pF                          |
| B2-05 | 备注里要有关键件标注，不能全部都没有关键件，至少有1个以上                                                                                                                           |
| B2-06 | 元器件数量与位号数量一致（数量 = 位号个数）                                                                                                                                 |
| B2-07 | 除了电阻、电容、PCB、屏蔽罩之外都要有品牌                                                                                                                                  |
| B2-08 | 单板BOM内部和外部文件名的名称、版本要一致                                                                                                                                  |
| B2-09 | 备注里标明“关键物料”或“关键器件”或“关键件”的物料要有物料编码，搜索电脑里E:\NAS\关键物料汇总表的《产品关键物料汇总表》，“关键物料”或“关键器件”或“关键件”要能在《产品关键物料汇总表》里找到，并且核对BOM的物料编码、型号要与产品关键物料汇总表的要一致，要查其他地方要咨询我授权后才能查找 |
| B2-10 | 单板BOM里无重复型号                                                                                                                                             |
| B2-11 | 单板BOM里如果有屏蔽罩的话要有位号                                                                                                                                      |
| B2-12 | 单板BOM里的型号与参数描述要对应                                                                                                                                       |
| B2-13 | 物料名称要与实际的型号、参数描述对应，尤其是电阻、电容、电感不能写错，比如实际是电容写成了电感                                                                                                         |
| B2-14 | 封面的产品名称、产品型号、物料编码、BOM版本与主页里的产品名称、产品型号、物料编码、版本一致                                                                                                         |
| B2-15 | 电容的容值如果在10pF以内（不含10pF）而且是C0G或NOG材质，精度要求是±0.1pF，不能写其他精度数值，大于10PF精度可以写1%                                                                                  |
| B2-16 | 不要和坐标文件对比器件位号和内容，不用坐标文件里的内容                                                                                                                             |
| B2-17 | 审批签署栏里可以没有内容                                                                                                                                            |
| B2-18 | 电阻电容外的其他器件型号与封装可能不是很直接明显的关联，比如型号里有0603字眼不代表是0603封装，如果怀疑的话要拿出证据证明有问题                                                                                     |
| B2-19 | 不要检查器件位号统一的问题                                                                                                                                           |
| B2-20 | 屏蔽罩的ERP编码和图号内容要一致                                                                                                                                       |

## 5. 规格书检查

| #    | 检查项                            |
| ---- | ------------------------------ |
| S-01 | 规格书里面的参数和指标要与测试报告里面的一致，有测试数据支持 |

## 6. 软件版本检查

| #    | 检查项                                        |
| :--- | :----------------------------------------- |
| R-01 | 《烧录软件》文件夹里的软件版本与《集成测试报告》文件夹里的测试报告内部软件版本号一致 |
