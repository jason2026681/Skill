### 硬件设计方案

| 序号 | 检查内容 | 备注 |
|------|----------|------|
| 1 | 先了解一下其他厂家的方案，列出其他厂家产品的器件列表和方案框图，分析其设计思路，尤其是不熟悉的领域 | |
| 2 | 关键器件尤其是CPU或MCU要找到原厂推荐，竞品用的型号不一定买的到或者不一定是主流 | |
| 3 | 关键器件要有原厂或代理阶梯报价，要能供货稳定可靠 | |
| 4 | FLASH和选型要预留升级所需空间 | |
| 5 | Flash和内存通常建议预留30% - 50% | |
| 6 | FLASH和内存如果有兼容封装而且空间允许尽量预留，市场上flash价格波动很大，选择主流供货厂家和型号 | |
| 7 | 调试串口等对外接口要注意是否倒灌，尤其是连接电脑调试通过串口有电到板卡，可能会烧芯片 | |
| 8 | 器件要有复位信号连接到MCU，如没有复位信号考虑可控电源供电 | |
| 9 | 常供电无法断电的设备要重点考虑异常恢复 | |
| 10 | 继电器控制AC220V建议用零点检测电路控制开关时间点，可以减少电弧 | |
| 11 | 关键继电器的控制状态要能读回，而且不能受CPU复位影响 | |
| 12 | 评审时要有硬件设计方案，含整体方案框图、关键信号连接、关键电路方案和器件等 | |
| 13 | 最好提出2-3方案对比 | |
| 14 | 要明确需要遵守的行标、规范、认证标准 | |

### 静电防护

| 序号 | 检查内容 | 备注 |
|------|----------|------|
| 1 | 整机对外信号的防护可以使用电容（放置在对外插座处，建议1nF或TVS）->串阻（放置在插座输入，建议100Ω）->电容（放置在靠近芯片处，建议0.1uF） | |
| 2 | 调试插座和下载插座等需要ESD防护电路，可以是串阻，必要时要用TVS，注意结电容不能影响信号速率 | |
| 3 | 非金属外壳的设备慎选金属壳体插座，空气静电不容易过，除非证明能通过要求的静电等级测试 | ⚠️ 爱迪尔网关塑料壳体，使用金属网口带灯插座，接触8KV和空气15KV都不能通过 |
| 4 | 非金属外壳的电源输入插座、天线插座等要注意外部与壳体、插座之间的缝隙会漏出里面的金属，空气静电时容易达到 | ⚠️ 爱迪尔网关的电源输入插座是DC电源适配器圆形插头，插入后与壳体之间有缝隙，空气静电15KV不能通过 |
| 5 | 非金属外壳的设备使用带灯网口容易静电测试灯的位置测试不通过，要将网口插座中LED PCB走线要避让高危风险信号和插座壳体，另外建议对灯的信号线使用隔离器件隔离处理 | ⚠️ 爱迪尔网关的网口插座有灯，静电测试不通过 |
| 6 | 非金属外壳如有网口，要选择无挖槽的型号，否则空气静电时会通过挖槽放电 | ⚠️ 爱迪尔网关的网口插座选择的是有挖槽的型号，导致空气放电不通过 |
| 7 | 电源适配器要选择头部有绝缘漆的型号 | ⚠️ 爱迪尔网关的电源适配器头部没有绝缘漆，空气放电会打到头部的金属部分不通过 |
| 8 | 射频天线连接器输入的部分如果空间允许、不影响射频性能的前提下增加ESD防护器件（注意结电容） | ⚠️ TP2510网关模块的天线没有加ESD，测试静电不能通过 |

### 网口

| 序号 | 检查内容 | 备注 |
|------|----------|------|
| 1 | CPU和网口PHY的时钟方向要确认（建议CPU的时钟为输入，PHY的时钟为输出，此点要看芯片的实际情况），优选开发板中的推荐（因为涉及到驱动），如驱动没有问题可以选择我们产品中用过的方案 | ⚠️ NXP的MCIMX6Y2CVM08AB的网口输出时钟存在bug，长时间运行会驱动能力弱化引起丢包 |

| 3 | MAC芯片在复位后才输出时钟给到PHY，因此PHY的复位要滞后于MAC芯片，可以用软件控制PHY复位管脚延迟，也可以复位信号串联电阻+电容增加延时，满足MAC和PHY之间和芯片自身的时序要求 | |
| 4 | 详细查看对外电平偏置电阻对应的信号电平值是否满足各种交换机连接要求，如有最大值取最大值 | ⚠️ TP2118的RESE电阻值用的是18K（不是12K），导致网口连接不同的交换机自协商有概率性不成功 |
